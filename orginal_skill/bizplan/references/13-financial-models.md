# 13 — 재무·사업비 표 5종 + 엑셀→이미지 삽입 (Gate 4 실행 + 본문 삽입)

> **이 문서는 12단계(수치 모델) 또는 16단계(초안에 재무표 삽입) 진입 시 Read 한다.**
> 입력은 `05-business-core/business-core.yaml`(확정 가정) + `04-research/source-index.xlsx`(출처).
> 출력은 `05-business-core/*.xlsx`(수식 포함 원본) → `07-diagrams/images/*.png`(캡쳐) → `08-draft/*.md` 본문 삽입.
> 도구: `scripts/build_xlsx.py`(spec.yaml→xlsx, `=`수식 보존, 인쇄설정), `scripts/xlsx_to_image.sh`(xlsx→PNG).

## 0. 핵심 원칙 — 손계산 금지, 엑셀이 계산한다

사업계획서의 **모든 금액·비율·합계는 엑셀에서 수식으로 계산**한다. 본문에 손으로 계산한 숫자를 박지 않는다.

```text
business-core.yaml (가정값)
        │
        ▼
spec.yaml  ── build_xlsx.py ──►  05-business-core/*.xlsx   (셀에 =B2*C2 수식 저장)
                                        │  soffice 가 수식 계산
                                        ▼
                                xlsx_to_image.sh ──► 07-diagrams/images/*.png
                                                          │  (셀강조·단위·trim 완료본)
                                                          ▼
                                            08-draft/*.md  ![표](images/*.png)
```

### 왜 수식인가 (절대 규칙과의 연결)

- **절대 규칙 #7 (숫자 일관성).** 손계산은 가정값이 바뀌면 검산이 안 된다. 수식이면 입력 1칸만 고치고 재캡쳐하면 전 표가 자동 갱신 → 코어·엑셀·본문이 갈라지지 않는다.
- **절대 규칙 #1 (임의 창작 금지).** 합계·파생수치는 AI가 암산해 적지 말 것. `=SUM(...)`·`=B2*C2`로 엑셀이 계산하게 한다. 입력 셀만 가정값, 나머지는 전부 수식.
- **절대 규칙 #2 (태그).** 모든 입력 셀은 `[사실]/[추정]/[가정]/[목표]`를 표 안 또는 하단 주석에 표기. 계산 셀(수식 결과)은 입력 셀의 태그를 상속한다.
- **절대 규칙 #3 (출처).** 입력 셀의 근거는 `src#NN`(source-index 행) 또는 `CF#NN`(confirmed-facts)으로 같은 표 또는 하단에 1:1 표기.

> **검산 가능성이 신뢰의 핵심이다.** 평가위원이 "이 숫자 어떻게 나왔나?"를 물으면 → 원본 .xlsx의 수식이 답이다. 그래서 캡쳐 이미지와 함께 원본 .xlsx를 항상 별첨한다(§5).

### build_xlsx.py 의 수식 동작 (반드시 이해)

`build_xlsx.py`의 `_coerce()`는 셀 값이 숫자/날짜로 "보이면" 그 타입으로 변환하고, 그 외 문자열은 그대로 둔다. **`=`로 시작하는 문자열은 openpyxl이 수식으로 저장**하고, soffice가 PDF 변환 시 계산한다. 따라서 spec.yaml의 `rows`에 `"=B2*C2"`처럼 쓰면 곧바로 계산식 셀이 된다.

- 입력값: `1200000` 또는 `"1,200,000"` → 숫자 1200000 (천단위 콤마 허용)
- 비율: `0.15` (15%면 0.15로 입력, 표시 단위는 "%" 열에 명시) — 또는 `15` 후 수식에서 `/100`
- 수식: `"=B2*C2*D2"` → 그대로 수식 셀 (셀 좌표는 **헤더가 1행이므로 데이터 첫 행 = 2행**)
- 합계: `"=SUM(B2:B6)"` → 범위 합계

⚠️ 셀 좌표 주의: 1행은 항상 헤더(컬럼명). 데이터 첫 행은 **2행**부터. spec.yaml `rows[0]`이 엑셀 2행이다.

### ① 시장규모 산정표 (TAM/SAM/SOM) → `market-sizing.xlsx`

**의도:** Bottom-up(SOM 필수, 투자자 선호) — `시장규모 = 고객수 × 단가 × 구매빈도`, 위로 SAM·TAM을 필터·점유율로 연결. 과장된 TAM보다 **보수적 SOM이 신뢰를 높인다**(리서치 노트 §F).

| 단계 | 산정방식 | 핵심 수식(엑셀 표기) |
|---|---|---|
| TAM | 전체 잠재고객수 × 연단가 × 빈도 | `=B2*C2*D2` |
| SAM | TAM × 도달가능 필터% | `=E2*F3` (E2=TAM, F3=필터%) |
| SOM | SAM × 목표 점유율% | `=E3*F4` (E3=SAM, F4=점유율%) |
| 연도성장 | 전년 × (1+성장률) | `=G4*(1+H5)` |

spec.yaml (`market-sizing.spec.yaml`):

```yaml
sheets:
  - name: "시장규모(TAM-SAM-SOM)"
    columns: ["구분", "고객수(명/사)", "연단가(원)", "구매빈도(회/년)", "시장규모(원)", "필터·점유율", "비고(근거)"]
    widths: [16, 16, 14, 14, 18, 14, 30]
    rows:
      # 2행 TAM: 고객수×단가×빈도
      - ["TAM 전체시장", 120000, 900000, 1, "=B2*C2*D2", "",        "[사실] src#07 통계청 사업체수"]
      # 3행 SAM = TAM(E2) × 필터%(F3)
      - ["SAM 유효시장", "",     "",     "",            "=E2*F3", 0.25, "[추정] src#09 도달가능 25%"]
      # 4행 SOM = SAM(E3) × 점유율%(F4)
      - ["SOM 수익시장(3년)", "", "",    "",            "=E3*F4", 0.03, "[목표] 3년차 점유 3% 보수적"]
```

> 캡쳐 전 강조: **SOM 행(E4)** 을 노란 배경 + 굵게. SOM = "3년 내 실제 가져올 돈"이 이 표의 결론이다.
> 하단 산식 병기: `SOM = SAM × 점유율(3%) = TAM × 25% × 3%`. Top-down·Bottom-up 둘 다 계산해 교차검증(`references/07-business-core.md §6`).

### ② 매출 추정 (bottom-up · 5개년) → `financial-model.xlsx` [매출추정 시트]

**의도:** 가격 × 수량으로 쌓는다. 플랫폼형이면 `MAU × 전환율 × 객단가`. 단가는 물가상승 반영, 고객수는 성장률 반영. 과도추정은 감점(리서치 노트 §C).

| 항목 | Y1 | 수식 패턴 |
|---|---|---|
| 유료고객수 | 입력(가정) | `=전년 × (1+성장률)` |
| 객단가(원) | 입력 | `=전년 × (1+물가)` |
| 매출(원) | — | `=고객수 × 객단가` |
| (플랫폼) 매출 | — | `=MAU × 전환율 × 객단가` |

spec.yaml (시트로 추가):

```yaml
  - name: "매출추정(5개년)"
    columns: ["항목", "Y1", "Y2", "Y3", "Y4", "Y5", "근거"]
    widths: [18, 13, 13, 13, 13, 13, 26]
    rows:
      # 2행 유료고객수 (Y1 입력, Y2~ = 전년×(1+성장률 30%))
      - ["유료고객수(사)", 50, "=B2*1.3", "=C2*1.3", "=D2*1.3", "=E2*1.3", "[가정] 성장률 30%/년"]
      # 3행 객단가 (Y1 입력, Y2~ = 전년×(1+물가 3%))
      - ["객단가(원/년)", 1080000, "=B3*1.03", "=C3*1.03", "=D3*1.03", "=E3*1.03", "[추정] 월90만×12 환산"]
      # 4행 매출 = 고객수 × 객단가
      - ["매출(원)", "=B2*B3", "=C2*C3", "=D2*D3", "=E2*E3", "=F2*F3", "[추정] 고객수×객단가"]
```

> 플랫폼/구독형이면 4행을 `=MAU×전환율×객단가`로 교체(MAU·전환율 행을 위에 추가). 강조: **Y3·Y5 매출 셀**.

### ③ 추정 손익계산서 (5개년) → `financial-model.xlsx` [추정손익 시트]

**의도:** 매출에서 단계별로 빼 내려가 영업이익·당기순이익까지. 원가·세금은 비율 수식으로(손계산 금지).

```
매출
 − 매출원가(=매출×원가율)        = 매출총이익
 − 판관비(=SUM 항목)            = 영업이익
 ± 영업외손익                   = 세전이익
 − 법인세(=세전×세율)           = 당기순이익
```

| 행 | 항목 | 수식(Y1=B열 기준) |
|---|---|---|
| 매출 | 매출추정 시트 참조 | `='매출추정(5개년)'!B4` |
| 매출원가 | 매출 × 원가율 | `=B2*0.4` |
| 매출총이익 | 매출 − 원가 | `=B2-B3` |
| 판관비 | 인건비+마케팅+기타 SUM | `=SUM(B6:B8)` |
| 영업이익 | 총이익 − 판관비 | `=B4-B5` |
| 세전이익 | 영업이익 ± 영업외 | `=B9+B10` |
| 법인세 | 세전 × 세율 | `=B11*0.1` |
| 당기순이익 | 세전 − 법인세 | `=B11-B12` |

spec.yaml (핵심 행만):

```yaml
  - name: "추정손익(5개년)"
    columns: ["항목", "Y1", "Y2", "Y3", "Y4", "Y5", "비고"]
    widths: [16, 14, 14, 14, 14, 14, 22]
    rows:
      - ["매출",        100000000, "=B2*1.34", "=C2*1.34", "=D2*1.34", "=E2*1.34", "[추정] 매출추정 시트"]
      - ["매출원가",    "=B2*0.4", "=C2*0.4",  "=D2*0.4",  "=E2*0.4",  "=F2*0.4",  "[가정] 원가율 40%"]
      - ["매출총이익",  "=B2-B3",  "=C2-C3",   "=D2-D3",   "=E2-E3",   "=F2-F3",   ""]
      - ["판관비",      30000000, "=B5*1.15", "=C5*1.15", "=D5*1.15", "=E5*1.15", "[가정] 인건+마케팅"]
      - ["영업이익",    "=B4-B5",  "=C4-C5",   "=D4-D5",   "=E4-E5",   "=F4-F5",   ""]
      - ["법인세",      "=MAX(B6,0)*0.1", "=MAX(C6,0)*0.1", "=MAX(D6,0)*0.1", "=MAX(E6,0)*0.1", "=MAX(F6,0)*0.1", "[가정] 세율 10%"]
      - ["당기순이익",  "=B6-B7",  "=C6-C7",   "=D6-D7",   "=E6-E7",   "=F6-F7",   ""]
```

> `=MAX(B6,0)*0.1` — 영업이익 적자면 법인세 0. 강조: **영업이익·당기순이익 행** + 흑자전환 연도 셀. 단위(원/백만원)를 표 상단에 명시.

### ④ 사업비 명세표 (직접비 + 간접비, 재원별) → `budget-detail.xlsx`

**의도:** 정부 R&D/창업과제 사업비 계상기준(innopolis 별표3 등). 인건비·연구수당·간접비는 **고시 산식**으로 계산 — 한도(연구수당 인건비 20% 등)를 수식에 박는다. 재원=정부지원금(현금)+자부담(현금+현물).

| 비목 | 산식 | 수식 |
|---|---|---|
| 인건비 | 연봉 × 참여율 × 기간(월/12) | `=B2*C2*D2/12` |
| 연구수당 | 인건비 × 20%(한도) | `=MIN(인건비*0.2, 인건비*0.2)` → 한도 내 |
| 재료비/장비비/활동비 | 입력(견적근거) | 입력값 + `src#`/견적 |
| 직접비 소계 | 비목 SUM | `=SUM(...)` |
| 간접비 | 직접비 × 기관 고시율 | `=직접비*0.15` |
| 총사업비 | 직접비 + 간접비 | `=직접비+간접비` |
| 재원 비중 | 재원 / 총사업비 | `=정부지원금/총사업비` |

spec.yaml (`budget-detail.spec.yaml`):

```yaml
sheets:
  - name: "사업비 명세(재원별)"
    columns: ["비목", "단가/연봉(원)", "참여율", "기간(월)", "산정액(원)", "정부지원금", "자부담현금", "자부담현물", "근거"]
    widths: [16, 16, 10, 10, 16, 16, 14, 14, 22]
    rows:
      # 2행 인건비 = 연봉×참여율×기간/12
      - ["인건비", 60000000, 0.5, 12, "=B2*C2*D2/12", "=E2", 0, 0, "[사실] CF#21 연봉·참여율"]
      # 3행 연구수당 = 인건비(E2)×20% 한도
      - ["연구수당", "", "", "", "=E2*0.2", "=E3", 0, 0, "[가정] 인건비 20% 한도"]
      # 4행 재료비 (견적 입력)
      - ["재료비", "", "", "", 15000000, 10000000, 5000000, 0, "[추정] 견적서 src#22"]
      # 5행 장비비 (현물 포함 예시)
      - ["장비비", "", "", "", 20000000, 14000000, 0, 6000000, "[사실] 보유장비 현물"]
      # 6행 직접비 소계 = SUM(2~5)
      - ["직접비 소계", "", "", "", "=SUM(E2:E5)", "=SUM(F2:F5)", "=SUM(G2:G5)", "=SUM(H2:H5)", ""]
      # 7행 간접비 = 직접비(E6)×고시율 15%
      - ["간접비", "", "", "", "=E6*0.15", "=E7", 0, 0, "[사실] 기관 고시율 15%"]
      # 8행 총사업비 = 직접비+간접비
      - ["총사업비", "", "", "", "=E6+E7", "=F6+F7", "=G6+G7", "=H6+H7", ""]
      # 9행 재원 비중 = 재원/총사업비
      - ["재원 비중(%)", "", "", "", "", "=F8/E8", "=G8/E8", "=H8/E8", "정부+자부담=100%"]
```

> 핵심 한도 — **연구수당 ≤ 인건비×20%**, **간접비 = 직접비×기관 고시율**(기관별 상이, 공고 확인). 강조: **총사업비 행 + 정부지원금 합계 셀**. 표가 길면 직접비/간접비 블록으로 분할(§5-3).
> ⚠️ 비목·한도·고시율은 **공고문/사업비 사용기준표 원본**을 따른다. 위 값은 예시 — 임의 적용 금지.

### ⑤ 단위경제성 (Unit Economics) → `financial-model.xlsx` [단위경제성 시트]

**의도:** 투자덱·사업성 평가의 핵심. `LTV/CAC ≥ 3`, 회수기간 `< 12개월`이 합격선(forentrepreneurs 기준).

| 지표 | 정의 | 수식 |
|---|---|---|
| ARPA(월) | 고객당 월 평균매출 | 입력 |
| GM% | 매출총이익률 | 입력(0~1) |
| Churn(월) | 월 이탈율 | 입력(0~1) |
| LTV | ARPA × GM% ÷ Churn | `=B2*B3/B4` |
| CAC | (영업비+마케팅비) ÷ 신규고객 | `=(B6+B7)/B8` |
| LTV/CAC | ≥3 합격 | `=B5/B9` |
| 회수기간(월) | CAC ÷ (월ARPA×GM%) <12 | `=B9/(B2*B3)` |

spec.yaml (시트로 추가):

```yaml
  - name: "단위경제성"
    columns: ["지표", "값", "판정기준", "근거"]
    widths: [18, 16, 16, 26]
    rows:
      - ["ARPA(월,원)", 90000, "",        "[추정] 객단가 월환산"]
      - ["매출총이익률 GM%", 0.6, "",       "[가정] 원가율 40%→GM 60%"]
      - ["월 이탈율 Churn", 0.03, "",       "[가정] 월 3%"]
      - ["LTV(원)", "=B2*B3/B4", "",        "=ARPA×GM%÷Churn"]
      - ["", "", "", ""]
      - ["영업비(원)", 5000000, "",         "[추정] 월 영업비"]
      - ["마케팅비(원)", 3000000, "",       "[추정] 월 마케팅비"]
      - ["신규고객(명)", 40, "",            "[추정] 월 신규"]
      - ["CAC(원)", "=(B7+B8)/B9", "",      "=(영업+마케팅)÷신규고객"]
      - ["LTV/CAC", "=B5/B10", "≥3 합격",   "건강성 핵심지표"]
      - ["회수기간(월)", "=B10/(B2*B3)", "<12 합격", "=CAC÷(월ARPA×GM%)"]
```

> 강조: **LTV/CAC 행, 회수기간 행** — 판정기준(≥3, <12)과 나란히. 미달이면 가정을 고치지 말고 솔직히 표시(절대 규칙 #1).

## 2. build_xlsx 실행 — spec.yaml → xlsx

spec.yaml을 `05-business-core/`에 두고 1개 .xlsx로 빌드한다(시트 여러 개면 한 spec에 `sheets:` 항목 나열).

```bash
python3 ~/.claude/skills/bizplan/scripts/build_xlsx.py \
  05-business-core/budget-detail.spec.yaml \

```

`build_xlsx.py`가 자동 적용하는 것: 헤더 파란 배경·필터·첫행 고정·열너비 자동 + **인쇄설정(landscape, fit-to-width)** — 캡쳐 시 표가 한 페이지 너비에 깔끔히 잡힌다.

### 셀 강조 (핵심 결과)

`build_xlsx.py`의 spec에는 셀 강조 옵션이 없다. 강조는 두 경로 중 하나:
- **(권장) 강조 위치를 안내하고 캡쳐 전 수기 처리** — soffice/엑셀로 열어 SOM·영업이익·정부지원금합계·LTV/CAC 셀에 노란 배경+굵게. 이미지는 사후편집 불가하므로 **캡쳐 전 강조 필수**(리서치 노트 §H-1).
- 또는 표 구조상 강조 행을 **맨 아래 "결론" 행**으로 분리해 시각적으로 두드러지게(예: SOM·총사업비를 굵은 제목 행으로).

각 표 §1의 "강조" 메모를 그대로 따른다.

## 5. 캡쳐 전 체크리스트 + 검수

### 5-1. 캡쳐 전 (이미지는 사후편집 불가 — 리서치 노트 §H)

- [ ] **셀 강조 완료** — SOM / 영업이익·당기순이익 / 정부지원금합계·총사업비 / LTV·CAC·회수기간
- [ ] **단위 명시** — 표 상단에 (단위: 백만원), 비율 열은 % 표기
- [ ] **출처·기준연도** — 입력 셀마다 `src#`/`CF#`, 기준 연도(예: 2026)
- [ ] **증거 태그** — 입력값 `[사실]/[추정]/[가정]/[목표]` (계산셀은 상속)

### 5-2. 캡쳐 후 검수 (PNG·수식 둘 다)

- [ ] PNG를 **Read 툴로 열어** 숫자 잘림·열 깨짐·공란 확인 (잘리면 DPI↑ 또는 표 분할 후 재캡쳐)
- [ ] **수식 검산** — 원본 .xlsx에서 SOM=SAM×점유율, 매출=고객수×객단가, 총사업비=직접비+간접비, LTV/CAC가 손계산과 일치하는지 1회 대조
- [ ] **숫자 일관성(절대 규칙 #7)** — 표의 핵심 수치가 `business-core.yaml`·`number-registry.md`·다른 표와 동일한지 (`references/07-business-core.md §4`)
- [ ] **과도추정 점검** — 성장률·점유율이 비현실적으로 높지 않은지(보수적 추정이 신뢰↑)

### 5-3. 표 분할 (길면 폰트 축소보다 분할 — 리서치 노트 §H-3)

- 5개년 표가 가로로 길면 → **Y1~Y3 / Y4~Y5** 두 표로
- 사업비 명세가 세로로 길면 → **직접비 블록 / 간접비·재원 블록** 두 표로
- 분할 시 각 spec.yaml을 별도 시트/파일로 만들어 별도 캡쳐. 폰트를 줄여 한 장에 우겨넣지 말 것(가독성).

## 6. 요약 — 한 사이클

```text
1. business-core.yaml 가정값 확인 (입력 셀 = 가정, 나머지 = 수식)
2. spec.yaml 작성 (=수식, 셀좌표는 데이터 첫행=2행)   →  05-business-core/*.spec.yaml

6. 08-draft/*.md 삽입 (캡션+수식1줄+단위·출처)

```
