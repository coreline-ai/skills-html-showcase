## ⚠️ 0. 가장 중요한 경고 — 논문 성능 ≠ 제품 성능 (7대 규칙 #6)

> **논문에 보고된 성능은 연구 환경의 결과다. 상용 제품 성능이 아니다.**

- 논문의 정확도·속도·비용을 사업계획서에 우리 제품 목표처럼 쓰지 않는다(PRD §29 논문 성능 과장).
- 연구 환경(데이터셋·하드웨어·실험 조건)과 실제 제품 환경을 항상 구분 표기.
- 논문 결과는 `[사실 — 연구환경]`, 우리 제품 수치는 `[목표]`로 태그 분리(7대 규칙 #2).
- **프리프린트는 동료 평가(peer-review) 논문과 명확히 구분**한다(§12.5).

---

## 1. 분석 목적 — 요약이 아니라 사업 연결 (PRD §12.1)

논문을 요약하는 것이 목적이 아니다. 아래 9개를 **사업과 연결**해야 완료다.

1. 현재 기술 수준
2. 대표적인 접근 방법
3. 기술적 한계
4. 검증된 성능
5. 사용 데이터
6. 재현 가능성
7. 상용화 장애물
8. 연구 공백 (= 우리 기회)
9. 사업의 기술개발 방향

→ "이 논문이 우리 사업의 무엇을 뒷받침/위협하는가"로 귀결되지 않는 요약은 범위 밖이다.

## 2. 검색 범위 (PRD §12.2)

- 학술지 논문 / 학회 논문
- 프리프린트 (arXiv 등 — 동료평가 전)
- 석·박사 학위논문
- 국가 연구보고서
- 기업 기술보고서
- 표준 문서
- 오픈소스 구현 (재현성 근거)
- 벤치마크 데이터셋

---

## 3. 공개 논문 검색 출처 (무료 접근 위주)

| 출처 | 범위 | 비고 |
|---|---|---|
| **arXiv** (arxiv.org) | 프리프린트(AI/물리/수학 등) | 무료, **동료평가 전임에 주의** |
| **Google Scholar** (scholar.google.com) | 전 분야, 인용수·관련논문 | 무료, 본문은 출판사 페이지로 |
| **Semantic Scholar** (semanticscholar.org) | 인용 그래프·TLDR 요약·영향력 | 무료 API |
| **DBpia** (dbpia.co.kr) | 국내 학술지 | 초록 무료, 본문 일부 유료 |
| **RISS** (riss.kr) | 국내 학위논문·학술지 | 무료 검색 |
| **PubMed** | 의학·생명과학 | 무료 (해당 도메인 시) |

- 무료 공개 출처와 초록을 우선 사용한다. 유료 본문·로그인 자료는 우회하지 않는다(PRD §3.2).
- 본문을 못 본 논문은 "초록 기반 — 본문 미확인"으로 명시하고, 그 한계 내에서만 인용(PRD §26 신뢰성).

## 4. 검색 전략 (PRD §12.3)

- 핵심 기술 키워드 + 동의어·유사 개념
- 대표 모델명 (해당 분야의 SOTA·기준 모델)
- 주요 연구자 / 주요 연구기관
- 인용 논문 (핵심 논문의 참고문헌·피인용 따라가기)
- **최신 리뷰 논문 / 메타 분석** (분야 지형을 빠르게 잡는 입구)
- 관련 데이터셋 / 기술 평가 지표

> 절차: ① 최신 리뷰 논문으로 분야 전체 지형 파악 → ② 핵심 논문 식별 → ③ 인용 그래프로 확장 → ④ 데이터셋·지표 기준으로 비교군 묶기. 사용 검색어 저장(재현성).

## 5. 논문별 분석 14개 항목 → paper-evidence-table.xlsx 컬럼 (PRD §12.4)

논문 1편 = `paper-evidence-table.xlsx` 1행. 14개 컬럼 모두 채운다.

| 컬럼 | 내용 |
|---|---|
| `title` | 논문명 |
| `authors` | 주요 저자 |
| `institution` | 대학·기업·연구기관 |
| `year` | 발행 연도 (최신성 판단) |
| `research_question` | 해결하려는 문제 |
| `methodology` | 모델·알고리즘·실험 방식 |
| `dataset` | 데이터 규모와 특성 |
| `metrics` | 평가 지표 (정확도·속도·비용 등) |
| `key_result` | 핵심 성능 |
| `limitation` | **저자가 밝힌 한계** |
| `reproducibility` | 코드·데이터 공개 여부 |
| `business_relevance` | 제품에 적용 가능한 부분 |
| `trl` | 기술 성숙도 (기초연구·실험·실증·상용화) |
| `follow_up` | 추가 개발 필요 항목 |
| `source_id` | source-index.xlsx 연결 ID |
| `peer_reviewed` | 동료평가 여부 (Y/N — 프리프린트 구분) |

## 6. 논문 품질 평가 체크리스트 (PRD §12.5)

논문마다 아래를 점검하고 신뢰도를 매긴다.

- [ ] **동료 평가 여부** (학술지/학회 vs 프리프린트)
- [ ] 표본 또는 데이터 규모 (작으면 일반화 주의)
- [ ] 비교 기준의 적절성 (공정한 baseline인가)
- [ ] 통계적 유의성
- [ ] 재현 가능한 방법인지
- [ ] 코드·데이터 공개 여부
- [ ] 연구비·이해관계 (특정 기업 후원 시 편향 가능)
- [ ] 실제 환경 검증 여부 (실험실 vs 현장)
- [ ] 최신 연구와의 일치 여부 (상충 시 표기)

> **프리프린트(arXiv 등)는 동료평가를 거치지 않았다.** `peer_reviewed=N`으로 분류하고, 핵심 근거로 쓸 때 "프리프린트, 미검증" 단서를 단다.

## 7. 기술 성숙도 / TRL (PRD §12.6)

논문에서 제안된 기술을 단계로 분류한다.

```text
기초 개념
→ 실험실 수준 검증
→ 제한된 환경의 프로토타입
→ 실제 환경 실증
→ 상용 제품 적용
```

- 필요 시 TRL(1~9) 형태로 표시. 우리 사업의 현재 단계와 목표 단계도 같은 척도로 표시해 격차를 보인다.
- "논문에서 실험실 검증됨"과 "상용 적용 가능"은 다른 단계임을 명시(§0 경고와 연결).

---

## 8. 벤치마크 분석 주의 — 조건 다르면 단순 비교 금지 (PRD §12.7)

논문 간 성능을 비교할 때 아래 조건이 같은지 먼저 확인한다. **다르면 숫자를 나란히 놓고 비교하지 않는다.**

- 동일한 **데이터셋**인가
- 동일한 **평가 지표**인가
- 동일한 **하드웨어 조건**인가
- **추론 비용**이 포함되었는가
- 품질과 속도의 균형
- 실제 제품 환경에서 재현 가능한가

### benchmark-comparison.xlsx 형식

| 컬럼 | 내용 |
|---|---|
| `method` | 모델·논문 |
| `dataset` | 데이터셋 (다르면 비교 불가 표시) |
| `metric` | 지표명 |
| `score` | 보고 점수 |
| `hardware` | 실험 하드웨어 |
| `inference_cost` | 추론 비용 포함 여부 |
| `comparable` | **비교 가능 여부 (Y/N)** — 조건 다르면 N |
| `note` | 비교 불가 사유 |

> `comparable=N`인 행끼리는 "X 점 > Y 점"식 서술 금지. 조건 차이를 함께 적는다.

## 9. 연구 공백 분석 = 우리 기회 (PRD §12.8)

논문 분석의 결론은 "빈틈"이다. 아래를 찾아 사업 기회로 연결한다.

- 아직 해결되지 않은 문제
- 특정 산업에 적용되지 않은 기술
- 데이터 부족 영역
- 사용성 또는 비용 문제
- 상용화되지 못한 이유
- **사용자의 현장 경험이 연구를 보완할 수 있는 부분** (founder-insight.md와 연결)

→ `research-gap-analysis.md`에 "연구 공백 → 우리 사업이 메우는 방식 → 차별성 근거"로 정리. 이것이 R&D 과제의 기술개발 방향·차별성의 핵심 근거다.

## 11. Gate 5(논문 부분) 체크리스트

- [ ] §0 경고문이 `paper-review-report.docx` 첫 페이지에 있음
- [ ] 논문 성능을 우리 제품 목표로 쓴 곳 0건 (연구환경=`[사실]`, 제품=`[목표]` 분리)
- [ ] **프리프린트와 동료평가 논문 구분** (`peer_reviewed` 컬럼 채움)
- [ ] 각 논문의 한계(`limitation`)·재현성 기록
- [ ] TRL로 기술 성숙도 + 우리 사업 격차 표시
- [ ] **조건 다른 벤치마크 단순 비교 0건** (`comparable=N` 행 비교 서술 없음)

- [ ] 본문 미확인 논문은 "초록 기반"으로 명시, 숨기지 않음
- [ ] 모든 논문이 `source-index.xlsx`에 등재 (DOI/식별자)
- [ ] research-report.md §14에 요약 반입
