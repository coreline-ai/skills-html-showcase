# BizPlan Architect 사용설명서 — 왕초보를 위한 안내서

> 사업계획서를 한 번도 써본 적 없어도 괜찮습니다. 이 안내서만 읽으면 시작할 수 있습니다.

---

## 1. 이게 뭔가요? (한 문장)

**막연한 사업 아이디어와 공고문 하나만 주면, AI가 직접 질문하고 자료를 조사해서 "심사에 통과할 수 있는 사업계획서"를 만들어 주는 도구**입니다.

비유하자면 — 빈칸을 채워주는 자동완성기가 아니라, **옆에서 깐깐하게 질문하고 근거를 찾아주는 컨설턴트**에 가깝습니다. 좋은 문장을 뽑아내는 게 아니라, "왜 이 사업이 되는지"를 따지고 증거를 붙입니다.

---

## 2. 어떤 분에게 필요한가요?

- 정부지원사업·창업지원에 도전하는데 **계획서를 처음 써보는** 예비창업자
- R&D 과제(기술개발 과제)에 지원하려는 **중소기업·연구소**
- 투자를 받으려고 **피치덱(IR 자료)**이 필요한 스타트업
- 기업·공공기관에 **제안서**를 내야 하는 담당자
- 여러 고객의 사업계획서를 빠르게 써야 하는 **컨설턴트**

> 완성된 사업계획이 없어도 됩니다. 키워드 몇 개와 아이디어만 있으면 AI가 질문으로 구체화합니다.

---

## 3. 무엇을 만들어 주나요? (결과물)

제출용 문서를 **6가지 형식**으로 만들어 줍니다:

| 형식 | 쓰임새 |
|---|---|
| **HWPX** | 한글(HWP) — 정부지원사업·공공기관 제출용 |
| **DOCX** | 워드 — 범용 제출·편집용 |
| **PDF** | 최종 제출·인쇄용 |
| **PPTX** | 투자 피치덱(발표 슬라이드) |
| **HTML** | 웹에서 바로 열어보는 미리보기 (다이어그램·표가 예쁘게 보임) |
| **XLSX** | 시장규모·재무모델·근거자료 정리 엑셀 |

여기에 더해 — 공고 분석 요약, 인터뷰 기록, 리서치 보고서, 평가위원 모의심사 결과, 제출 체크리스트까지 단계별로 다 남습니다.

---

## 4. 어떻게 시작하나요? (사용법)

채팅창에 이렇게 말하면 됩니다:

```
/bizplan
```

또는 그냥 평소 말로:

- "이 공고 분석해서 사업계획서 써줘" + (공고 링크 붙여넣기)
- "R&D 계획서 작성하고 싶어"
- "투자 피치덱 만들어줘"

**준비물**(있으면 좋지만 없어도 됩니다):
- 공고문 URL 또는 파일 (정부지원·R&D의 경우)
- 사업 아이디어 키워드 (예: "AI로 코딩 자동화")

나머지는 AI가 질문으로 채워갑니다. 객관식으로 물어보니 고르기만 하면 됩니다.

---

## 5. 어떻게 작동하나요? (7단계)

AI는 **바로 글을 쓰지 않습니다.** 아래 순서로 차근차근 진행하고, 각 단계마다 결과를 남깁니다.

1. **공고 분석** 📋 — 공고문과 첨부파일을 모아 "무슨 사업이고, 어떻게 평가하는지(배점표)"를 파악합니다.
2. **심층 인터뷰** 🎤 — "누구의 어떤 문제를 푸나요?", "왜 지금인가요?" 같은 질문을 던져 사업을 구체화합니다. (한 번에 3개씩, 객관식)
3. **리서치** 🔍 — 시장 규모·경쟁사·기술 논문·특허를 직접 조사합니다. **우리에게 불리한 자료까지** 정직하게 찾습니다.
4. **사업 코어 확정** 🎯 — 조사한 내용을 하나의 "사업 설계도"로 정리합니다. 이후 모든 문서가 여기서 나옵니다.
5. **서식 매핑 & 그림** 🗺️ — 공식 서식에 내용을 배치하고, 문제 구조도·시스템 그림 등을 만듭니다.
6. **초안 작성** ✍️ — 평가 배점에 맞춰 계획서를 씁니다.
7. **평가위원 모의심사** ⚖️ — 4명의 가상 심사위원(행정·기술·사업성·깐깐한 반대자)이 점수를 매기고 약점을 지적합니다. → 고쳐서 완성.

> 각 단계는 "통과 기준"을 넘어야 다음으로 갑니다. 중간에 멈춰도 이어서 다시 할 수 있습니다.

---

## 6. 이 도구의 가장 중요한 약속 🤝

사업계획서에서 제일 위험한 건 **"그럴듯한 거짓말"**입니다. AI가 없는 고객·매출·실적을 지어내면 심사에서 바로 들킵니다. 그래서 이 도구는 **7가지 규칙**을 철칙으로 지킵니다. 그중 핵심 3가지만 쉽게 말하면:

- **지어내지 않습니다.** 모르는 건 비워두고 `[확인 필요]`라고 솔직히 표시합니다.
- **모든 숫자에 출처를 붙입니다.** "시장이 크다"가 아니라 "○○ 보고서 기준 1.2조원"처럼.
- **표시를 구분합니다** — `[사실]`(확인됨) / `[추정]`(계산) / `[가정]`(아직 미검증) / `[목표]`(앞으로 달성) / `[확인 필요]`.

이렇게 하면 **심사위원의 반론을 견디는** 계획서가 됩니다.

---

## 7. 어디에 쓸 수 있나요? (활용 분야)

- 정부 창업지원사업 (예비창업패키지, 초기창업패키지, 창업도약패키지 등)
- 중소기업 R&D / 기술개발 과제 (중기부, TIPA 등)
- 산학협력 과제
- 투자 유치용 IR 피치덱
- 기업·공공기관 입찰 제안서
- 사내 신사업 기획서

같은 사업 아이디어 하나로 **여러 종류의 문서**(정부지원서·R&D계획서·투자덱·제안서)를 만들 수 있습니다. 평가 관점만 바꿔서 변환하기 때문입니다.

---

## 8. 실제 사례 — IRIS 정부 R&D 공고

실제로 이렇게 작동했습니다:

> **입력**: IRIS(국가 R&D 포털) 공고 링크 하나 + "AI로 코딩 자동화" 아이디어

1. 공고 링크를 열어보니 **MIT(미국)와 공동연구하는 R&D 사업**이었습니다. AI가 첨부파일 5개(공고문·세부지원내용·서식)를 자동으로 받아 분석해 **"6개월·1.1억원, 평가 1순위는 국제공동연구 필요성"**임을 파악했습니다.
2. 객관식 인터뷰로 사업을 **"개발자용 AI 코딩·테스트 에이전트"**로 구체화했습니다.
3. 시장·경쟁·논문·특허를 조사하면서 **우리에게 불리한 사실**(국내에도 비슷한 우수 연구가 있다는 점)까지 찾아내, 사업 논리를 더 탄탄하게 바꿨습니다.
4. 평가위원 모의심사에서 **계산 오류 2건**(예산 규칙 위반, 매출 단위 10배 오류)을 잡아내 수정했습니다.
5. 최종적으로 HWPX·PDF·HTML 등으로 계획서를 출력했습니다.

→ **핵심**: AI가 똑똑한 문장을 쓴 게 아니라, **따지고·조사하고·자기 실수를 잡아낸** 것이 가치였습니다.

## 9. 결과물은 어디에 저장되나요?

스킬 폴더 안 **`dist/` 폴더**에 사업별로 정리됩니다:

```
dist/bizplan-<사업이름>/
├── 01-notice-analysis/   ← 공고 분석
├── 02-interview/         ← 인터뷰 기록
├── 04-research/          ← 리서치 보고서·출처
├── 05-business-core/     ← 사업 설계도·엑셀
├── 09-audit/             ← 평가위원 심사 결과
└── 10-final/             ← 📦 최종 제출 파일 (HWPX/PDF/HTML/DOCX)
```

제출할 파일은 **`10-final/` 폴더**만 보면 됩니다.

---

## 10. 꼭 알아두세요 (주의사항) ⚠️

- **마지막엔 꼭 사람이 검토하세요.** AI가 만든 초안이지, 그대로 제출용 완성본이 아닙니다. `[확인 필요]` 표시된 곳(실제 고객·팀·매출 등)은 본인이 채워야 합니다.
- **특허 분석은 참고용입니다.** 침해 여부 등 법적 판단은 반드시 **변리사**에게 확인하세요.
- **공고 마감일을 꼭 확인하세요.** AI는 마감이 지나도 작성해주지만(연습용), 실제 제출 가능 여부는 본인이 챙겨야 합니다.
- **로그인이 필요한 자료**는 AI가 대신 받지 않습니다. 직접 다운로드해서 주면 분석합니다.

## 11. 자주 묻는 질문 (FAQ)

**Q. 사업 아이디어가 아직 막연한데 괜찮나요?**
네. 오히려 그게 정상입니다. AI가 객관식 질문으로 같이 구체화합니다.

**Q. 한글(HWP) 정부 서식도 되나요?**
네, HWPX로 출력됩니다. 다만 정부 지정 서식의 세밀한 칸 맞춤은 한/글에서 최종 확인이 필요합니다.

**Q. 중간에 멈췄다가 다시 할 수 있나요?**
네. 진행 상태가 저장되어 있어서 멈춘 단계부터 이어집니다.

**Q. AI가 시장 수치를 지어낼까 봐 걱정돼요.**
이 도구의 1순위 규칙이 "지어내기 금지"입니다. 출처 없는 수치는 쓰지 않고, 모르면 `[확인 필요]`로 남깁니다.

**Q. 결과물을 수정하고 싶어요.**
HTML로 먼저 미리보기 하고, DOCX/HWPX 파일을 워드·한글에서 직접 고치면 됩니다.
