# storm-contradict: 모순 지도

> "아무도 못 본 것"은 대개 **충돌 지점에 숨어 있다**. 이 스킬은 다섯 관점을 봉합하지 않고
> 부딪히는 곳을 그대로 드러낸다. Co-STORM의 moderator 역할.

## 언제

- `/storm-scan`(또는 5영혼 딥리서치)으로 다관점 자료가 모인 뒤.
- 여러 출처·시각이 서로 엇갈려 *무엇이 진짜 쟁점인지* 모를 때.
- `/storm-research` 풀 파이프라인의 2단계로 자동 호출되기도 한다.

## 입력

- **다관점 스캔 출력** (필수): storm-scan 결과 또는 5영혼의 results 모음 (출처 포함).
- 주제 한 줄.

## 실행

`prompts/2-contradiction-map.md`의 프롬프트에 스캔 출력을 `{{SCAN_OUTPUT}}`으로 넣어 실행.
모더레이터로서 다음 4층을 만든다:

1. **합의 (Consensus)** — 둘 이상이 같은 결론. 동의한 전문가 + 출처 묶음.
2. **모순 (Contradiction)** — 정면 충돌. 각 모순마다 표:
   | 충돌 대상 | A 입장 (+출처) | B 입장 (+출처) | 미해결 이유 |
3. **사각지대 (Blind Spot)** — 누구도 안 다뤘지만 중요한 질문.
4. **핵심 긴장 (Key Tension)** — 주제를 가르는 단 하나의 충돌. 왜 가장 중요한지.

## 출력

```
## {주제} — 모순 지도
### 합의 지점
### 모순 지점 (표)
### 사각지대
### 핵심 긴장 (한 개 + 이유)
```

## 규칙 (HARD)

- **모순을 인위적으로 봉합 금지.** 진짜 충돌은 충돌로 남기는 것이 가치.
- 각 입장에 **원래 출처를 그대로** 끌고 온다. 출처 없는 모순은 무효.
- "양쪽 다 일리 있다"로 끝내지 말고 **무엇이 해결되면 충돌이 풀리는지** 명시 (데이터 부족/가치관/시간지평).
