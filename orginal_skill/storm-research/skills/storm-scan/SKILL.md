# storm-scan: 다중 관점 스캔

> Stanford STORM(NAACL 2024)의 핵심 — "하나의 질문 대신 다섯 전문가의 질문". 단일 시각은
> 누구나 아는 것을 주지만, 충돌하는 다섯 렌즈는 *아무도 못 본 것*을 드러낸다.
> 출처: 논문 https://arxiv.org/abs/2402.14207 · 진짜 도구 https://storm.genie.stanford.edu

## 언제

- 사용자가 주제 하나를 깊이 조사하고 싶을 때, 특히 **편향 없이 여러 시각**을 원할 때.
- `/storm-research` 풀 파이프라인의 1단계로 자동 호출되기도 한다.
- 단독으로도 완결 — 그냥 다관점 리서치 한 방.

## 입력

- **주제** (필수): 조사할 주제 한 줄.
- 웹 검색 도구 가용 여부 (WebSearch/WebFetch 등). 있으면 각 렌즈가 1차 출처를 끌어온다.

## 실행

1. 주제를 확인한다. 모호하면 한 번만 되묻는다 (범위·기간·지역).
2. `prompts/1-multi-perspective-scan.md`의 프롬프트를 `{{TOPIC}}`에 치환해 실행한다.
   (이 스킬은 `../../prompts/1-multi-perspective-scan.md`를 SSOT로 참조 — 심링크 경로에선
   `~/.claude/skills/storm-research/prompts/1-multi-perspective-scan.md`.)
3. 다섯 관점 각각:
   - 그 렌즈로 **실제 웹 검색**을 돌려 (가용 시) 1차 출처를 수집.
   - 가장 중요한 발견 3가지 + 각 주장에 `[출처: URL]`.
   - 고유 결론 1줄 + 불확실성 1줄.
4. **다섯 관점이 서로 다른 것을 발견했는지 자가 점검**. 겹치면 그 렌즈의 질문을 다시 던진다.

## 다섯 렌즈 (기본 팩)

| 영혼 | 핵심 질문 |
|---|---|
| 회의주의자 | 가장 강한 반론·반증은? |
| 경제학자 | 누가 이득을 보는가? 인센티브는? |
| 역사학자 | 닮은 과거 선례와 결말은? |
| 학자 | peer-reviewed 증거가 말하는 것은? |
| 미래학자 | 2차 효과·시나리오는? |

주제에 따라 관점을 재도출할 수 있다 (예: 양자컴퓨팅 → 물리학자/암호학자/VC/정책/회의주의자).
**단, 회의주의자는 항상 유지** (편향 방어).

## 출력

```
## {주제} — 다중 관점 스캔
### 1. 회의주의자 관점 (발견 3 + 출처 + 결론 + 불확실성)
### 2. 경제학자 관점 …
### 3. 역사학자 관점 …
### 4. 학자 관점 …
### 5. 미래학자 관점 …
### 통합 참고 출처 (전체 URL, 중복 제거)
```

## 규칙 (HARD)

- **출처 없는 단언 금지.** 모든 사실 주장에 `[출처: URL]`. 추측은 `[추론]` 라벨.
- 다섯 관점은 **서로 달라야** 한다 — 같은 말 반복은 실패.
- 검색 도구가 없거나 실패하면 그 사실을 명시하고, 추측으로 출처를 위조하지 않는다.
