# storm-synthesize: 종합

> 종합은 **평균이 아니라 충돌을 통과한 판단**이다. 다섯 관점을 한 전문가로 수렴시키지 않고,
> 핵심 긴장을 축으로 *논지가 있는 글*을 짠다. 인용은 끝까지 유지.

## 언제

- `/storm-contradict`로 모순 지도가 나온 뒤.
- 흩어진 다관점 자료를 **읽을 수 있는 하나의 글**로 만들 때.
- `/storm-research` 풀 파이프라인의 3단계로 자동 호출되기도 한다.

## 입력

- **다관점 스캔 출력** (`{{SCAN_OUTPUT}}`) + **모순 지도** (`{{CONTRADICTION_MAP}}`).
- 주제 한 줄.

## 실행 (`prompts/3-synthesis.md` 기반)

1. **개요 (Outline Generation)** — 계층적 개요. **모순 지도의 핵심 긴장을 중심 축**으로.
   각 섹션은 하나의 질문에 답하고, 어떤 출처를 쓸지 표기.
2. **본문 (Article Generation)** — 개요를 따라 집필:
   - 모든 사실 주장에 인용 `[출처: URL]` 유지.
   - 모순은 본문에서 정면으로 다룬다 ("X는 A를 시사하지만 Y의 증거는 B를 가리킨다").
   - 한 관점으로 수렴하지 말고 **종합적 판단**을 제시. 증거 부족 시 "미해결"로 정직하게.
   - 확신 등급을 본문에 녹임 ([확립]/[수렴 중]/[논쟁]).
3. **Lead** — 맨 앞 3~4문장 요약 (핵심 긴장 + 종합 판단 압축).

## 출력 (Markdown)

```
# {주제}
> (lead 3~4문장)
## (섹션들 — 각 인용 포함)
## 미해결 질문
## 참고 출처 (전체 URL, 중복 제거)
```

## 규칙 (HARD)

- **출처 누락 금지** — 이 산출물이 그대로 HTML 리포트 본문이 된다.
- **한 관점으로 수렴 금지** — 충돌을 통과한 판단을 쓰되, 증거 부족은 미해결로 명시.
- **가짜 확실성 금지** — 확신 등급을 정직하게.
