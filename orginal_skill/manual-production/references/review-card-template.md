# Review Card Template

Use one review card per lesson/video/major manual artifact.

```md
# Review Card: <Lesson or Artifact Title>

## Purpose
- Target reader:
- Job/task taught:
- Expected outcome:

## Source Grounding
- App/system/environment:
- Routes/screens covered:
- Data/fixtures used:
- Date/time checked:

## Included
- Screens/actions shown:
- Decisions explained:
- Verification points:

## Excluded
- Out-of-scope screens/actions:
- Risky actions intentionally not performed:
- Product issues blocked or deferred:

## Technical QA
- Links/routes:
- Images/video/embed:
- Console/runtime/export health:
- Result: PASS / FAIL / PARTIAL

## Content QA
- Reader fit:
- Coverage:
- Lesson split:
- Impossible states or UI drift:
- Result: PASS / FAIL / PARTIAL

## Notes / Follow-up
- Product bugs:
- Manual edits needed:
- Owner decisions:
```
