LIBRARY · coreline-auth

호스트 프로젝트에 종속되지 않는 파이썬 인증 코어

coreline-auth는 이메일/비밀번호 로그인부터 OAuth/OIDC, TOTP MFA, WebAuthn 패스키, RBAC 권한, 세션·감사 저장소까지 하나의 프레임워크 독립 모듈로 묶은 파이썬 인증 라이브러리입니다. 프로토콜 기반 어댑터로 저장소·이메일·레이트리미터·MFA 볼트를 교체할 수 있고, FastAPI 어댑터로 라우트를 바로 마운트합니다.

Python 3.12+ framework-agnostic core FastAPI 어댑터 포함 버전 0.5.0-rc2 (README 표기 · 확인 필요)

핵심 가치

인증의 "어려운 부분"을 라이브러리 안에 두고, 앱은 어댑터만 연결합니다.

비밀번호 해싱, 토큰 일회성 소비, 세션 회전, MFA 시크릿 암호화, OIDC 토큰 검증 같은 보안 결정은 한번 잘못하면 조용히 취약점이 됩니다. coreline-auth는 이런 결정을 서비스 계층 안에 캡슐화하고, 저장소·이메일·레이트리미터·MFA 볼트·메트릭 싱크를 모두 프로토콜(Protocol)로 노출합니다.

덕분에 호스트 앱은 자신의 인프라(메모리·SQLite·Postgres·Redis·SMTP)에 맞는 어댑터만 끼우면 되고, 라이브러리는 호스트 프로젝트를 절대 import 하지 않는 단방향 의존성을 유지합니다.

STEP 1 · 설치

패키지 추가

코어만 설치하거나, Postgres 비동기 어댑터를 함께 설치합니다.

# 코어 설치
uv add coreline-auth

# Postgres 비동기 어댑터 포함
uv sync --extra postgres
STEP 2 · 저장소 + 서비스 연결

어댑터를 서비스에 주입

저장소 어댑터를 고르고 CorelineAuthService 에 주입합니다. 아래는 단일 소유자(single_owner) 프로파일 예시입니다.

from coreline_auth import (
    CorelineAuthConfig, CorelineAuthService, AuthProfile,
)
from coreline_auth.storage import SQLiteAuthStorage

storage = SQLiteAuthStorage("/var/lib/coreline-auth/auth.sqlite3")
auth = CorelineAuthService(
    storage=storage,
    config=CorelineAuthConfig(
        profile=AuthProfile.SINGLE_OWNER,
        owner_email="owner@example.com",
        session_ttl_seconds=86400 * 7,
        revoke_sessions_on_password_change=True,
    ),
)
auth.bootstrap_owner(email="owner@example.com", password="change-me-strong-pw")
STEP 3 · FastAPI 라우트 마운트

인증·관리자 라우트 연결

FastAPI 어댑터가 로그인/세션/관리자 라우트를 마운트합니다. secure_cookies 는 운영 기본값이 True 이며, 로컬 HTTP 데모는 명시적으로 끄도록 설계되어 있습니다.

from fastapi import FastAPI
from coreline_auth import CsrfProtector
from coreline_auth.fastapi_adapter import (
    mount_auth_routes, mount_admin_routes,
)

app = FastAPI()
csrf = CsrfProtector(secret_key="<32+ 자 고엔트로피 시크릿>")
mount_auth_routes(app, auth, csrf_protector=csrf, secure_cookies=True)
mount_admin_routes(app, auth, csrf_protector=csrf)
STEP 4 · 의존성으로 보호

세션·권한 확인

라우트는 의존성 팩토리로 보호합니다. require_session 은 유효 세션을, require_permission 은 특정 권한 문자열을 요구합니다.

from fastapi import Depends
from coreline_auth.fastapi_adapter import (
    require_session, require_permission,
)

@app.get("/me", dependencies=[Depends(require_session(auth))])
def me(): ...

@app.post("/posts", dependencies=[Depends(require_permission(auth, "posts:write"))])
def create_post(): ...

FAQ

누구를 위한 라이브러리인가요?

직접 인증·세션·권한 코어를 다뤄야 하는 파이썬 백엔드 개발자를 위한 것입니다. 단일 소유자(개인 SaaS)부터 다중 사용자 RBAC 프로파일까지 지원하며, 호스트 앱에 종속되지 않는 재사용 가능한 인증 코어를 목표로 합니다.

FastAPI 가 꼭 필요한가요?

코어 서비스(CorelineAuthService)는 프레임워크 독립적입니다. FastAPI 어댑터(fastapi_adapter.py)는 별도 제공되는 통합 계층일 뿐이며, 다른 웹 프레임워크에서는 서비스 API 를 직접 호출해 연결할 수 있습니다.

패스키(WebAuthn)와 MFA 를 지원하나요?

네. TOTP 등록/검증·복구 코드·AAL2 스텝업이 mfa.py 에, 패스키 등록/어서션 검증과 서명 카운터 재사용 거부가 webauthn.py 에 구현돼 있습니다. 다만 브라우저 어테스테이션 파싱 같은 일부 항목은 README 에서 호스트 책임(범위 외)으로 명시합니다.

어떤 저장소를 쓸 수 있나요?

테스트·데모용 MemoryAuthStorage, 단일 노드용 SQLiteAuthStorage(WAL·busy_timeout), 다중 노드용 비동기 AsyncPostgresAuthStorage(SQLAlchemy + Alembic)가 있습니다. 저장소는 프로토콜이라 직접 구현한 어댑터로 교체할 수도 있습니다.
