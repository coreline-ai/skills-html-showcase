EXECUTIVE SUMMARY

Coreline Auth는 독립 인증 모듈, 세션, RBAC, 관리자 코어, MFA, OAuth/OIDC, 운영 readiness CLI를 갖춘 release-candidate 수준의 패키지입니다. 강점은 독립 경계, hash-only token 저장, Argon2id, HMAC CSRF, Redis/Postgres 확장성, audit redaction입니다. 공개 멀티유저 SaaS GA로 보기에는 fail-closed 구성, external dependency evidence, passkey 완성도, admin step-up 정책, release hygiene가 남은 조건입니다.

2Decision cards

각 영역을 decision card로 판단해 임원/엔지니어가 같은 결론을 공유합니다.

D-01 독립 경계

GO. `src/coreline_auth`는 CoreMCP import 없이 독립 모듈이어야 하며, CI import guard가 release blocker가 되어야 합니다.

D-02 Password/Token

Conditional GO. hash-only 원칙은 좋습니다. production profile의 NIST Rev.4 password length/blocklist 정책 분리가 필요합니다.

D-03 Cookie/CSRF

Conditional GO. session-bound HMAC CSRF는 적절하지만, cookie state-changing route는 protector 누락 시 fail-closed가 기본이어야 합니다.

D-04 OAuth/OIDC

Conditional GO. PKCE, nonce, issuer/audience/azp/nbf/max_age, JWKS negative tests가 provider별로 필요합니다.

D-05 Passkey

TOTP Conditional / Passkey NO-GO for primary. helper groundwork는 있으나 full ceremony, attestation, credential lifecycle이 필요합니다.

D-06 Operations

Conditional GO. JSONL SIEM, Prometheus, readiness는 강점이나 retention, alert threshold, secret DLP가 release artifact가 되어야 합니다.

4Hardening roadmap

RC를 신뢰 가능한 beta로 만드는 4단계 로드맵입니다.

PHASE 0 · RELEASE HYGIENE

pyproject, README, CHANGELOG 버전 일치, clean release branch, full tests, smoke-demo-secure, import guard, SBOM, secret-safe readiness 결과를 evidence로 저장합니다.

PHASE 1 · FAIL-CLOSED

CSRF required, MFA vault production guard, admin AAL2 step-up, password blocklist hook, Redis limiter mandatory, audit sink secret DLP guard를 기본값으로 올립니다.

PHASE 2 · SAAS CERTIFICATION

Postgres migration apply/rollback, Redis TLS/auth/namespace, SMTP delivery, backup/restore, SIEM forwarding, OAuth provider negative tests를 배포 문턱으로 삼습니다.

PHASE 3 · IDENTITY ASSURANCE

full WebAuthn/passkey ceremony, recovery UX, device inventory, risk-based step-up, suspicious session revoke, admin break-glass audit를 구현합니다.

5Validation checklist

릴리스 전 반드시 실패/성공을 증명해야 하는 항목입니다.

PASS CRITERIA

원문 secret 저장 없음, 세션 revoke 즉시 반영, CSRF 누락 실패, TOTP replay 차단, exact RP/origin 검증, PKCE/nonce/ID token 검증, audit redaction 검증.

RELEASE BLOCKERS

CoreMCP 역방향 import, production no-CSRF adapter, in-memory MFA vault production 사용, social login ID token 미검증, release version 불일치, 테스트 evidence 없음.
