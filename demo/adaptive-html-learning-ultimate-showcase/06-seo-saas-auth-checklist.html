5발행 체크리스트

Google Search Central 관점에서 유용하고 탐색 가능한 문서가 되어야 합니다.

  • 한 페이지에 하나의 명확한 H1과 논리적인 h2/h3 구조를 둔다.
  • 표준 출처는 본문 중 필요한 곳에만 연결하고, 전체 링크는 source hub로 낮춘다.
  • 체크리스트 PDF/복사 CTA를 제공해 실무 효용을 만든다.
  • 각 클러스터 문서에서 pillar로 내부 링크를 되돌린다.
  • 업데이트 날짜와 검토 기준을 명시한다.
  • FAQ는 실제 검색 질문 중심으로 구성하고 schema는 과장하지 않는다.
