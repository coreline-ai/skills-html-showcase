1Executive Decision

현 작업 트리는 독립 인증 모듈로서 v0.5.0rc1 release candidate에 필요한 핵심 보안 패치를 통과했다. 단, async service를 전체 production facade로 오해하지 않도록 문서화하고, custom email template에서 raw variable 사용을 제한하는 가이드를 추가해야 한다.

결론

동기 CorelineAuthService + SQLite/Postgres 저장소 + 명시적 encrypted MFA vault 조합은 조건부 릴리스 가능 상태다.

4Validation Checklist

AuthZ

`post:*:own`이 `post:delete:any`를 거부한다.

Session

password change 이후 기존 session token이 실패한다.

MFA

동일 TOTP code 재사용과 brute-force 모두 차단된다.

CSRF

cookie-auth admin POST는 protector 없으면 실패한다.

OIDC

PKCE, nonce, ID token issuer/audience 검증이 연결된다.

Storage

raw token/password/magic-link 원문은 DB에 없다.

✓전문가 검토 의견

릴리스 전 마지막 관문은 코드가 아니라 운영 문서다. 보안 기능은 존재만으로 충분하지 않고, host app이 안전한 조합으로 인스턴스화하도록 “실패하기 어려운” 예제와 체크리스트가 필요하다.

S조사·검토 출처
