이 내용을 전문가용 HTML 리포트로 만들어줘.

필수 구성:
- Executive Summary: 결론/우선순위/즉시 조치/주의점을 분리한다.
- Decision Cards: 최소 4개. 각 카드에 판단, 근거, 실행 포인트를 넣는다.
- Operating Model: 최소 5행 이상의 표 또는 카드로 책임, 산출물, 주기, 판단 기준을 정리한다.
- RACI 또는 책임 배분: Responsible/Accountable/Consulted/Informed를 구분한다.
- Risk Matrix: 최소 4개 리스크에 영향도, 가능성, 통제책, 검증 방법을 넣는다.
- 90일 Roadmap: 0~30일, 31~60일, 61~90일 실행 흐름과 산출물을 제시한다.
- Validation Checklist: 완료 기준과 증빙 자료를 포함한다.

금지:
- 섹션당 1~2문장 요약만으로 끝내지 않는다.
- 표/캡션/카드 텍스트가 모바일에서 잘리는 CSS를 쓰지 않는다.
- 확인되지 않은 최신 사실은 단정하지 말고 출처 또는 확인 필요로 표시한다.
