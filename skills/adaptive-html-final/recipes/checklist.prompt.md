이 내용을 체크리스트/플레이북 HTML(운영 절차 스타일)로 만들어줘.

필수 구성:
- Use Case: 이 체크리스트를 언제 누가 쓰는지 적용 상황을 요약 카드로 정리한다.
- Check Grid: 점검 항목을 체크 그리드로 구조화한다. 항목마다 판단 기준을 둔다.
- Failure Modes: 자주 나오는 실패 모드와 그 대응을 정리한다.
- Done Criteria: 완료로 볼 수 있는 기준을 마지막에 명확히 둔다.
- 주요 h2에는 부제(h2-sub)를 붙인다.

금지:
- 항목을 막연하게 두지 말고 통과/실패를 판단할 수 있게 적는다.
- 확인되지 않은 절차/기준은 단정하지 말고 확인 필요로 표시한다.
