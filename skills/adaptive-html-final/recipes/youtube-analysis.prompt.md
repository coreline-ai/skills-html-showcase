# YouTube Analysis Prompt

```text
다음 YouTube URL/트랜스크립트/댓글 메모를 `youtube_analysis` 모드로 분석해줘.

요구:
- profile=auto
- TL;DW, Video Evidence Map, Comment Signal Wall, Claim/Evidence/Risk, Source Limits 포함
- FACT / INFERENCE / UNKNOWN을 분리
- observed_at 또는 분석 기준 시각 표시
- iframe/player/embed 없이 무 JS HTML로 출력

입력:
<YouTube URL 또는 transcript/comment/metadata 붙여넣기>
```
