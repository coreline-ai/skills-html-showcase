필요한 것은 GitHub 계정, 브라우저, 간단한 HTML 파일입니다.

3개념 설명

GitHub Pages는 저장소의 파일을 정적 웹사이트로 보여주는 기능입니다.

저장소가 서랍이라면 GitHub Pages는 그 서랍 속 문서를 전시장에 걸어주는 기능입니다.
