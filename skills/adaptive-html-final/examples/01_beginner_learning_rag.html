RAG를 처음 이해하는 가장 쉬운 방법

검색해서 찾고, 필요한 부분만 꺼내서, AI가 답하게 만드는 흐름을 초보자용 학습자료로 설명합니다.

모드: beginner레이아웃: learning path폭: 760px
RAG는 ‘똑똑한 오픈북 시험’입니다. AI가 머릿속 기억만으로 답하지 않고, 필요한 자료를 펼쳐 보고 답하게 만드는 방식입니다.
학습 순서
  1. 먼저 한 줄로 이해하기
  2. 용어 풀이
  3. 일상 비유
  4. 초보자 함정
  5. 따라 해볼 것

0먼저 이것만 알면 됩니다

RAG는 AI에게 외부 자료를 연결하는 방법입니다. 모델을 다시 학습시키지 않아도, 문서 검색 결과를 참고해서 답하게 할 수 있습니다.

1용어를 쉽게 풀기

Retrieval은 필요한 자료를 찾는 과정이고, Generation은 찾은 자료를 바탕으로 답을 쓰는 과정입니다.

2일상 비유로 이해하기

시험장에서 아무 자료 없이 답하는 것이 일반 LLM이라면, RAG는 교과서와 필기노트를 찾아본 뒤 답하는 방식입니다.

3초보자 함정

RAG를 쓰면 무조건 정확해진다고 생각하면 안 됩니다. 검색된 자료가 틀리거나 관련이 없으면 답변도 흔들립니다.

4따라 해볼 최소 구조

문서 수집 → 문서 쪼개기 → 임베딩 → 검색 → 답변 생성
