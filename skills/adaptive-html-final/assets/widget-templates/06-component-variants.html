버튼 컴포넌트 변형

한 버튼 컴포넌트의 모든 변형(Variant) × 크기 × 상태를 한 시트에 정렬했습니다.

배경 토글
행 = 변형 · 열 = 상태 · 셀 내부 = 크기(L/M/S)
Variant \ State Default Hover Focus Disabled
Primary hover focus ring disabled
Secondary hover focus ring disabled
Ghost hover focus ring disabled
Danger hover focus ring disabled

Default 열의 버튼은 실제 :hover / :focus-visible 가 동작합니다. 나머지 열은 상태를 고정 시뮬레이션해 한눈에 비교하도록 했습니다.
