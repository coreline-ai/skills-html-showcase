    스폰서·RACI 합의, 단가 산식 초안 고시. ~D0.

    텔레메트리 스키마 강제, 단가 대시보드 가동. 커버리지 95% 목표.

  3. M2 · 게이트 자동화 (31~60일)예정

    CI에 cost-budget·eval 이중 게이트 적용, 우회 승인 로그화.

  4. M3 · 절감·정착 (61~90일)예정

    캐시·배치·양자화 ROI순 적용, 분기 비용 리뷰 정례화.
