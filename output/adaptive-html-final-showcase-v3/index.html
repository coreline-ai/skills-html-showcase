`adaptive-html-final` 스킬의 13개 모드를 각각 다른 주제로 실행해 만든 전문가급 한국어 HTML 결과물 모음입니다. 모든 페이지는 스킬의 editorial 디자인 시스템(theme · components · layouts · print CSS)을 inline으로 포함한 독립 실행 HTML이며, v3 레이아웃 안전·디자인 폴리시 패치와 자동 검증 게이트를 적용했습니다.

1작업 방식

스킬 라우터의 13개 모드를 빠짐없이 사용해, 모드별 레이아웃에 실제 콘텐츠를 채웠습니다.

각 주제를 해당 모드로 라우팅한 뒤, 모드별 레이아웃 골격(assets/layouts/*.html)에 editorial 콘텐츠를 작성하고 theme.css + components.css + layouts.css + print.css를 inline으로 결합했습니다. 생성 직후 모든 페이지를 품질 게이트(단일 h1, #main skip target, h2 부제, 모바일 안전 표, 외부 JS 금지, 미확인 정보 단정 금지, source-note)로 적대적 검수하고 위반은 보정했습니다.

생성 파이프라인

주제 → 모드 라우팅 → 레이아웃 선택 → editorial 렌더링 → 품질 게이트 검증·보정 → 단일 HTML 조립
