추가 데모 · Visual Template System v4.3.3

섹션별 이미지 전략 데모

고해상도 이미지는 장식이 아니라 이해·판단·검증을 돕는 정보 구조여야 합니다. 이 페이지는 adaptive-html-final v4.3.3의 Visual Template System으로 만든 8000×6000 SVG 인포그래픽 5종을 실제 섹션에 삽입한 결과입니다. 모든 그림은 외부 검색 없이 스킬의 render_visual_svg.py가 stdlib만으로 생성했습니다.

visual-template-system 8000×6000 SVG · 5종 외부 JS·이미지 0 figure + figcaption

1왜 기본값이 SVG 인포그래픽인가

사진·AI 이미지보다 정보 전달·재현성·접근성에서 유리하기 때문입니다.

현실의 인물·장소·제품·사건을 보여줘야 할 때는 공개 라이선스 사진이 맞습니다. 하지만 절차, 비교, 정책, 리스크, 학습 구조처럼 관계와 순서를 보여줘야 하는 정보는 직접 그린 인포그래픽이 가장 정확합니다. 텍스트가 벡터로 살아 있어 확대해도 깨지지 않고, 본문과 1:1로 정합을 맞출 수 있으며, 출처 분쟁이나 라이선스 위험도 없습니다.
