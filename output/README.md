# output/ — 날짜별 산출물 아카이브

이 디렉터리는 `adaptive-html-final` 스킬의 **과거 생성 결과물·공개 데모·테스트 산출물**을 담는다.
스킬의 단일 출처(source of truth)는 `skills/adaptive-html-final/`이며, `output/`의 존재는 스킬 생성 로직에 영향을 주지 않는다.

## 정리 규칙 (결정론)

- 각 산출물 폴더는 **최초 생성된 날짜**(폴더명 날짜 우선, 없으면 git 최초 커밋일 기준) 아래 `output/YYYY-MM-DD/`로 배치한다.
- 새 산출물을 만들 때도 동일 규칙으로 해당 날짜 폴더에 넣는다(예: `output/2026-06-14/<산출물명>/`).
- `playwright/`(렌더 캐시)는 gitignore 대상이라 날짜 분류에서 제외한다.
