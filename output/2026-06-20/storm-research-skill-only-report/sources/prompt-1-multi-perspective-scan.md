# 프롬프트 1 — Multi-Perspective Scan (다중 관점 스캔)

> STORM의 *Perspective-Guided Question Asking* + *Knowledge Curation*을 단일 프롬프트로 압축.
> 하나의 질문 대신, 다섯 전문가의 다섯 렌즈로 주제를 훑는다.
> 복붙용 — `{{TOPIC}}`을 주제로 치환. 출처를 끌어올 수 있는 환경(웹 검색)에서 실행하면 효과 최대.

---

```
당신은 리서치 코디네이터입니다. 주제 "{{TOPIC}}"를 단일 시각이 아니라
서로 충돌하는 다섯 전문가의 렌즈로 조사하세요.

다섯 전문가:
1. 회의주의자 — 가장 강한 반론과 반증 증거는?
2. 경제학자 — 누가 이득을 보는가? 인센티브와 자본 흐름은?
3. 역사학자 — 구조적으로 닮은 과거 선례와 그 결말은?
4. 학자(실증주의자) — peer-reviewed 증거가 실제로 말하는 것은? 합의 수준은?
5. 미래학자 — 2차·3차 효과와 가장 그럴듯한 시나리오는?

각 전문가에 대해:
- 그 렌즈에서 가장 중요한 발견 3가지를 쓰세요.
- 모든 주장 끝에 출처를 [출처: URL] 형식으로 박으세요. 출처 없는 단언 금지.
- 그 전문가만의 고유한 결론 1줄.
- 그 전문가가 확신하지 못하는 불확실성 1줄.

규칙:
- 다섯 전문가는 서로 다른 것을 발견해야 합니다. 같은 말을 반복하면 실패입니다.
- 검색 도구가 있으면 각 렌즈마다 다른 검색어로 1차 출처를 끌어오세요.
- 추측과 출처 있는 사실을 섞지 마세요. 추측은 [추론]으로 라벨.

출력: 다섯 전문가 섹션 + 각 섹션 끝에 그 전문가의 참고 출처 목록.
```

---

## 사용 메모

- **단독**: 이 프롬프트 하나만 Claude/GPT에 붙여도 다관점 리서치가 된다.
- **본 스킬 파이프라인**: 메인이 5영혼을 5개 LLM 페인에 분산해 *진짜로 5개 모델이 병렬 리서치*
  → 이 프롬프트의 "한 모델 안 다섯 역할"보다 한 단계 강한 버전. 결과는 다음 프롬프트(모순 지도)로.
- 출처 강제가 핵심. 출처 없는 다관점은 그냥 브레인스토밍이다.
