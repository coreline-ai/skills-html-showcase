## 개발 목적

완성된 editorial HTML을 공유·인쇄·썸네일·외부 배포용으로 변환한다.

- 입력: 자기완결 HTML 산출물 디렉터리
- 출력: PDF / PNG / webp 산출물과 상세 manifest
- 핵심 요구: `:has()` 기반 CSS-only 테마, 인라인 CSS, 대형 SVG, 무 JS 출력물의 시각 충실도 유지
- 최종 방향: **A안 유지 — Node Playwright(Chromium) 렌더 + sharp 기반 webp 파생, 스킬 본체와 분리**

전문가 병렬 검토 결론은 **KEEP with ADJUST**다. Playwright/Chromium과 sharp 선택은 맞지만, PDF 테마 상태 누수, WebP 16383px 한계, 긴 페이지 메모리, dark2 처리, manifest/exit code/HTML 무수정 증명은 계획서에 반드시 보강해야 한다.

## CLI 계약

기본 형태:

```bash
node scripts/export_output.mjs <output_dir> \
  --formats pdf,png,webp \
  --themes light,light2,white,dark,dark2 \
  --scale 2 \
  --viewport 1280x900
```

v1 허용 옵션(단일 출처):

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--formats` | `pdf,png,webp` | 생성 포맷 |
| `--themes` | `light,light2,white,dark,dark2` | 요청 테마. DOM에 없는 테마는 skip |
| `--scale` | `2` | PNG deviceScaleFactor 요청값. 16384 가드로 페이지별 `scale_used`가 낮아질 수 있음 |
| `--viewport` | `1280x900` | Chromium viewport |

### v1 MVP / v2 연기 범위 (2차 거버넌스 반영)

빌드 보조 도구의 표면적을 줄이기 위해 v1은 **6개 옵션**으로 고정한다.

- **v1 유지(6개):** `--formats`, `--themes`, `--scale`, `--viewport`, `--require-webp`, `--clean`
- **v2 연기:** `--webp-mode chunks`(원해상도는 PNG master로 충족), `--pdf-media screen`/`--pdf-themes`(print PDF 1종이면 충분), `--show-controls`(기본 숨김이 공유 정답), `--concurrency`(기본 1 고정, 초장문 메모리와 충돌), `--offline`/`--strict-fonts`(폰트 결정론 미해결 영역), `--pdf-format`/`--pdf-margin`/`--webp-quality`/`--webp-max-edge`(기본값 고정, 노출은 v2)

## 변환별 상세 조건

### 1. 페이지 수집

- 수집 대상:
  - `root/*.html`
  - `root/pages/*.html`
- 정렬:
  - `index.html` 우선
  - 나머지는 상대 경로 문자열 정렬
- 제외:
  - `exports/`
  - `_work/`
  - 숨김 디렉터리
  - non-html 파일
- 주의:
  - `output/final_20260604/index-beginner-width.html`처럼 root에 있는 보조 HTML도 반드시 포함한다.

### 2. 렌더 안정화

- `pathToFileURL(absPath).href`로 로드
- `page.goto(url, { waitUntil: 'load' })`
- `page.waitForLoadState('networkidle', { timeout: <short> })`는 best-effort
- `document.fonts.ready` timeout
- `document.images` decode timeout
- `reducedMotion:'reduce'`
- screenshot에는 `animations:'disabled'` 사용
- `animation-play-state:paused` 전역 주입은 기본 금지

### 3. 테마 적용

- DOM 기준 존재 확인:

```js
input[type="radio"][name="ahf-theme"]#ahf-${theme}
```

- 존재하면 runtime에서 `checked=true`로 전환하고 `:has()`/sibling selector 재평가를 기다린다. 무 JS 출력물이므로 이벤트 dispatch는 필수 아님
- 존재하지 않으면 skip
- `light2`/`dark2`는 **DOM radio가 존재하는 출력에서만 캡처하는 출력별 확장 테마**다. `final_20260604`에서는 정식 버튼/토큰이 있으므로 생성하고, 13-topics·github/grok 계열에는 없으므로 skip한다.
- themebar/control은 기본 export에서 숨김:
  - `.ahf-themebar`
  - `.reading-progress`
  - `.skip`
  - `.ahf-color-audit`
- v1은 위 control을 항상 숨긴다. `--show-controls`는 v2 reserve이며 v1 CLI는 `not implemented in v1`로 거부한다.

### 4. PNG

- 기본: `page.screenshot({ fullPage:true, path, animations:'disabled' })`
- context: `deviceScaleFactor = effectiveScale` (`--scale` 요청값에서 16384 가드에 따라 자동 강등 가능)
- preflight:
  - `scrollWidth`
  - `scrollHeight`
  - `pixelWidth = scrollWidth * effectiveScale`
  - `pixelHeight = scrollHeight * effectiveScale`
  - `rawBytes = pixelWidth * pixelHeight * 4`
- raw memory estimate를 manifest와 로그에 기록
- PNG는 원본 master로 보존하고 다운스케일하지 않는다.
- `scrollHeight * requestedScale`이 16384를 넘으면 `scale_used`를 1까지 자동 강등하고 `scale_degraded:true`로 기록한다.
- scale 1에서도 긴 변이 16384를 넘는 페이지는 실제 Chromium full-page screenshot을 우선 시도하고 `soft_raster_limit_exceeded:true`로 기록한다. 픽셀 수가 `PNG_PIXEL_MAX`를 넘는 경우에만 artifact fail 또는 향후 `png chunks` 옵션으로 분리한다.

### 5. WebP

- 입력은 반드시 저장된 PNG master 파일.
- sharp 사용:
  - `sharp(pngPath)`
  - 긴 변 > 16383이면 `resize({ width: 16383, height: 16383, fit:'inside', withoutEnlargement:true })`
  - `.webp({ quality: 85, smartSubsample:true, effort:6, alphaQuality:100 })`
- 기본 mode:
  - `full`: 긴 변 ≤ 16383
  - `downscaled`: 긴 변 > 16383
- v2 reserve mode:
  - `chunks`: 원해상도 보존이 필요한 경우 `part001`, `part002`로 분할. v1 CLI에서는 `not implemented in v1`로 거부
- 단일 원해상도 WebP가 16383px를 초과하면 **REJECT**.

### 6. PDF

- 기본 print PDF:
  - fresh page/context를 강제한다. PDF 직전 `#ahf-light` reset 경로는 사용하지 않는다
  - `page.emulateMedia({ media:'print' })`
  - `page.pdf({ printBackground:true, preferCSSPageSize:true, format: pdfFormat, margin })`
- `preferCSSPageSize:true`는 유지하되, `print.css`에 `@page`가 없을 수 있으므로 `format/margin` 기본값을 명시한다.
- screen PDF는 v2 reserve다. v1에서는 `--pdf-media screen`/`--pdf-themes` 입력 시 `not implemented in v1` + exit 2로 명확히 거부한다.

### 7. 실패 / exit 정책

- 페이지/테마/포맷 단위 try-catch
- 실패 artifact는 manifest에 `status:'failed'`, `error` 기록
- skip artifact는 `status:'skipped'`, `skipped_reason` 기록
- 최종 exit:
  - pdf/png required artifact 실패 → exit 1
  - sharp 없음으로 webp skip → 기본 exit 0
  - `--require-webp`일 때 webp skip/fail → exit 1
- manifest는 실패가 있어도 항상 작성한다.

### R8. PNG: per-page context + 16384 자동 강등 (G10 해결)
deviceScaleFactor는 **context 단위**라 per-screenshot 변경 불가 → **페이지마다 effectiveScale로 context를 만든다.** scrollHeight는 CSS px라 dsf·테마와 무관(레이아웃 동일).
```
async function exportPngForPage(browser, pageMeta, opts):
  // 1) 강등 판단용 높이 측정(dsf1 임시 context)
  m = measureScrollHeight(browser, pageMeta.url)          // scrollWidth/scrollHeight
  effScale = opts.scale
  while effScale > 1 and (m.scrollHeight*effScale > RASTER_MAX or m.scrollWidth*effScale > RASTER_MAX):
    effScale -= 1                                        // scale 1까지 자동 강등
  pixelCount = m.scrollHeight*m.scrollWidth*effScale*effScale
  if pixelCount > PNG_PIXEL_MAX: return [{status:'failed', error:ERR.RASTER}]
  soft_raster_limit_exceeded = (m.scrollHeight*effScale > RASTER_MAX or m.scrollWidth*effScale > RASTER_MAX)
  // 2) 실제 context
  ctx = browser.newContext({viewport:opts.viewport, deviceScaleFactor:effScale, reducedMotion:'reduce'})
  page = ctx.newPage(); page.goto(url,{waitUntil:'load',timeout:nav}); waitStable(page); hideControls(page)
  themes = detectThemes(page); if empty: themes=[null]    // 테마 없는 출력 fallback(suffix 없음)
  pf = preflight(page, effScale)                          // manifest 기록
```

### R9. WebP (정확 sharp 호출)
```js
let sharp=null; try{ sharp=(await import('sharp')).default; }catch{}   // import throw도 흡수
async function exportWebpFromPng(pngPath, webpPath, q){
  if(!sharp) return {status:'skipped', skipped_reason:ERR.SHARP_NA};
  sharp.concurrency(1); sharp.cache(false);
  try{
    const img = sharp(pngPath,{ limitInputPixels:false, sequentialRead:true });
    const m = await img.metadata();
    const down = Math.max(m.width,m.height) > DEFAULTS.webpMaxEdge;
    let p = img;
    if(down) p = p.resize({ width:DEFAULTS.webpMaxEdge, height:DEFAULTS.webpMaxEdge,
      fit:'inside', withoutEnlargement:true, kernel:'lanczos3' });
    const info = await p.withIccProfile('srgb')   // sharp ^0.33.5 API (구버전: .withMetadata({icc:'srgb'}))
      .webp({ quality:q, smartSubsample:true, effort:6, alphaQuality:100 }).toFile(webpPath+'.part');
    atomicArtifact(webpPath+'.part', webpPath);
    return { status:'ok', path:webpPath, source_path:pngPath, source_width:m.width, source_height:m.height,
      output_width:info.width, output_height:info.height, webp_quality:q,
      webp_mode: down?'downscaled':'full', webp_downscaled:down,
      webp_downscale_ratio: down ? +(info.height/m.height).toFixed(3) : 1 };
  }catch(e){ return { status:'failed', error: /pixel/i.test(e.message)?ERR.INPUT_PX:ERR.RENDER }; }
}
```

```js
function cleanExports(outputDir, formats){
  const exportsDir = path.resolve(outputDir,'exports');
  if(!fs.existsSync(exportsDir)) return;
  if(fs.lstatSync(exportsDir).isSymbolicLink()) { exit(EXIT.PRECONDITION); } // 심링크 거부
  for(const fmt of formats){                       // pdf|png|webp 화이트리스트만

}
```

## 잔여 리스크 / 후속 과제

- 초장문 PNG 자체가 Chromium 한계에 닿는 경우 `png chunks` 또는 section capture 옵션이 필요할 수 있다.
- WebP chunk 모드는 v1에서 옵션/TODO로 둘 수 있으나, 원해상도 WebP 요구가 생기면 필수화해야 한다.
- CDN 폰트 완전 결정론이 필요하면 후속으로 로컬 폰트 임베드 또는 폰트 캐시 정책을 설계해야 한다.
- `light2`/`dark2`는 **`final_20260604` 계열의 정식 확장 테마**(독립 라디오·라벨·토큰 블록·배지)이며, 13-topics·github-analysis·grok 출력엔 라디오가 없어 skip된다(P0-7/P0-10). 향후 스킬 테마 계약이 전 출력 5테마로 통일되면 export의 기본 테마 셋은 그대로 유지하고 각 출력의 DOM radio가 실제 생성 여부를 결정한다. "DOM radio 존재 시 캡처"는 출력별 테마 셋 차이를 흡수하는 메커니즘이지 light2/dark2를 격하하는 의미가 아니다.
