## 2. A1 설계 (forced-colors)
배경색만으로 선택/체크 상태를 표현하는 컨트롤은 Windows 고대비(forced-colors)에서 배경이 시스템 색으로 치환되어 상태가 소실된다. 시스템 색상 키워드(`Highlight`/`HighlightText`/`CanvasText`)와 `outline`/`border`로 단서를 복원한다.

- **theme-dark.css** — 테마바 선택 라벨:
  ```css
  @media (forced-colors: active){
    .ahf-themebar input:checked + label{ outline:3px solid Highlight; outline-offset:-3px }
  }
  ```
- **widgets.css** — 체크/선택 상태 컨트롤(수집 단계에서 확정한 셀렉터 목록)에 동일 패턴의 `@media (forced-colors: active)` 블록 1개를 자산 끝에 추가. 각 선택 상태에 `outline`(또는 `border`) + 필요한 경우 `forced-color-adjust:none`.

설계 제약: 코어/평상시 렌더에는 **영향 0**(forced-colors 비활성에선 미적용) → 일반 프로브 diff에 안 잡혀야 정상. forced-colors 에뮬레이션 프로브에서만 단서 출현 확인.
