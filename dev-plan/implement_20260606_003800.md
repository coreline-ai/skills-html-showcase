## 개발 목적

`adaptive-html-final`에 14번째 모드인 `github_analysis`를 추가한다. 사용자가 GitHub 저장소 URL 또는 `owner/repo`를 제공하면, 단순 README 요약이 아니라 사용자가 가장 궁금해하는 의사결정 질문 중심으로 저장소를 분석하고 한국어 HTML 리포트로 정리하는 스킬 모드로 만든다.

## 개발 범위

- `github_analysis` 모드 라우팅, 우선순위, 트리거, 레이아웃, vt-/wg- 매핑 추가.
- `github-analysis.html` 레이아웃 골격과 `.layout-github` CSS 추가.
- GitHub 분석용 글쓰기/정보 구조/검증 기준을 references에 반영.
- manifest, README/Guide/AGENTS, 테스트 체크리스트, golden prompt, recipe 동기화.
- 기존 무 JS, 3-테마, profile=widget|diagram|auto 계약 유지.

## 제외 범위

- GitHub API 클라이언트/크롤러/토큰 관리 스크립트 구현.

- 위젯 또는 vt- 템플릿 신규 번호 추가.
- 외부/동작 JS 추가.
