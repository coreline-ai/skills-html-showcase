## 잔여 리스크 / 후속 과제

- 신규 모드 3개를 한 번에 추가하면 priority, examples count, governance count, package sync 표면이 커져 회귀 위험이 높다. 첫 릴리스는 `business_plan_html` 단일 모드로 끝까지 검증하는 것이 안전하다.
- `storm_research`는 외부 리서치/출처와 source snapshot 계약이 강하므로 custom gate 설계 없이 mode JSON만 추가하면 “전문가 리포트”와 구분되지 않는다.
- `social_trend_dashboard`는 원본이 JS dashboard라서 no-JS 정적 표현으로 재설계하지 않으면 `adaptive-html-final` 불변식을 위반한다.
- `operator_manual_html`은 multi-page package와 media/video까지 포함하면 `adaptive-html-final` 단일 HTML 모드 범위를 넘을 수 있다. `manual_analysis` 강화 후 별도 모드화를 재판단한다.
