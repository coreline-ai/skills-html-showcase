## 개발 목적

반복되던 문제를 다음 원칙으로 차단한다.

| 문제 | 이번 작업의 해결 방향 |
|---|---|
| 검증은 통과하지만 사용자가 보는 결과물이 어긋남 | `validate`만 완료 기준으로 보지 않고 `quality`·`completion`·브라우저 render-audit를 분리 확인 |
| 공식 템플릿을 읽지 않고 유사 shell을 작성 | `build-evidence.json`에 공식 파일 경로+sha256을 기록하고, 누락/stale을 completion에서 실패 처리 |
| 텍스트-only 섹션·비정본 클래스가 통과 | `quality_contract_check.py`에 flat text-only section·비정본 클래스 차단 추가 |
| v5.10.4 버전/게이트 표면 불일치 | manifest `version/examples.version/governance_count`를 단일 출처로 맞추고 README 표면 동기화 |
| output 결과물이 스킬 정본으로 오해됨 | output은 독립 QA 산출물이며, 스킬 정본은 `skills/adaptive-html-final/`과 `examples/`임을 분리 |
